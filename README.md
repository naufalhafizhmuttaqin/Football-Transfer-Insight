# Football Transfer Insight - Player Potential Prediction

## Project Overview

This project builds a **Machine Learning Regression Model** to predict football player potential scores based on performance attributes.

The objective is to simulate a **data-driven scouting and transfer decision system** that helps identify high-potential players across different positions.

Workflow:
> Data Understanding → Exploratory Data Analysis → Feature Selection → Regression Modeling → Evaluation → Scouting Insight

---

## Problem Statement

In football recruitment and scouting, identifying high-potential players early provides strategic advantage.

This project aims to:

- Predict player potential score using technical attributes
- Identify key performance drivers influencing potential
- Rank top predicted players per position
- Support transfer market insights with data

---

## Dataset

Dataset: `transfer_insight.csv`

### Features Used:
- age
- speed
- stamina
- shooting
- passing
- dribbling

### Target Variable:
- potential_score (continuous numeric value)

Additional columns:
- name (player name)
- position (player role)
